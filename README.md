## ⚡ Quick Start: 다른 LLM에 바로 붙여넣기 (One-Click Setup)

ChatGPT, Claude, Gemini, DeepSeek 등의 시스템 프롬프트(System Prompt), 커스텀 인스트럭션(Custom Instructions), 또는 프로젝트 프롬프트(Project Prompt)에 아래 파일의 내용을 그대로 복사해 붙여넣으면, LLM이 즉시 **Delta Squared의 수석 에디터 및 시장 분석관**으로 동작합니다.

👉 **[📄 LLM_SYSTEM_PROMPT.md 열기 및 복사하기](LLM_SYSTEM_PROMPT.md)**

### 💡 포함되어 있는 핵심 프롬프트 기능
1. **DTSQ 브랜드 철학 & 페르소나**: 표면적 뉴스 너머의 비용 구조, 자금 흐름, 인센티브 분석.
2. **5대 서브브랜드 모드 자동 전환**: DTSQ AI, Finance, Crypto, Korea, Lifestyle 전문 앵글 탑재.
3. **4대 문체 제어**: 언론체(`Tone 1`), 해요체(`Tone 2`), 해석체/음슴체(`Tone 3`), 명사체(`Tone 4`).
4. **5대 제작 포맷 표준**: 인사이트 브리핑, 장문 칼럼, 숏폼 대본, 카드뉴스 슬라이드, 실증 리뷰.
5. **엄격한 품질 필터**: 기계적 AI 클리셰 전면 배제 및 팩트 기반 검증 원칙.
