# 📦 Guide 05: Brand Assets Directory & Specs

Delta Squared (DTSQ) 공식 브랜드 에셋의 파일 구조, 포맷 스펙, 다운로드 가이드입니다.

---

## 1. Directory Structure

```
assets/
├── symbols/       # 심볼 마크 단독 (4종 컬러 × SVG/PNG)
├── lockups/       # 로고 + 워드마크 조합형 (한/영 × 가로/세로/슬로건)
├── subbrands/     # 5대 서브브랜드 엠블럼 및 디바이더 (1080px 고화질)
├── mascot/        # 공식 마스코트 델리(Delli) 3D 렌더 및 표정 팩
├── posters/       # 키 비주얼 및 수평 포스터
└── visual/        # 소셜 채널 배너 및 브랜딩 그래픽
```

---

## 2. File Specifications

- **Vector Formats (`.svg`)**: 웹사이트, 앱 UI, 반응형 인터페이스, 인쇄물용 무한 해상도 벡터.
- **Raster Formats (`.png`)**: 
  - 심볼 및 로고: 1080px ~ 2160px 고해상도 투명 배경(Transparent).
  - 마스코트 델리: 오프화이트 배경 418×627 px 렌더링 세트 및 1254×1254 px 2D 프로필.
